# Design Patterns in Go

Small, runnable examples of common design patterns, written in Go while learning how each
pattern works.

| File | Pattern | Kind |
|---|---|---|
| `singleton.go` | Singleton | Creational |
| `Factory.go` | Factory Method | Creational |
| `abstractfactory.go` | Abstract Factory | Creational |
| `Builder.go` | Builder | Creational |
| `phototype.go` | Prototype | Creational |
| `adapter.go` | Adapter | Structural |
| `facade.go` | Facade | Structural |
| `proxy.go` | Proxy | Structural |
| `strategy.go` | Strategy | Behavioural |
| `command.go` | Command | Behavioural |
| `errorwrapper.go` | Error wrapping | Go idiom |

## Run

Each file is a separate program with its own `main`, so run one at a time:

```sh
go run singleton.go
```
